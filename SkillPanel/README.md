# Aerolt - Skill Panel

An add-on for Aerolt that adds a **Skills** tab for inspecting and controlling the
selected player's skill slots — handy for testing skills, cooldown reduction, and stock.

## Requires

- Aerolt

## What it shows

For each slot (Primary, Secondary, Utility, Special): skill name, current/max stock, and
cooldown remaining (or "ready"). Updates live.

## Controls

- **Reset Cooldowns** — instantly refill stock and clear cooldowns once.
- **Infinite stock / no cooldown** — while on, keeps every skill fully stocked and off
  cooldown each frame.

Acts on the player selected in Aerolt's top bar.
