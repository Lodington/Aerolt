# Aerolt - Item Loadouts

An add-on for [Aerolt](https://thunderstore.io/c/riskofrain2/p/Lodington/Aerolt/) that adds a **Loadouts** tab for saving and quickly
reloading item sets — handy for testing runs.

## Requires

- Aerolt

## How to use

1. Open Aerolt (F1 or the top-left icon) and go to the **Loadouts** tab.
2. Grab the items you want, then type a name and click **Add Profile**. This saves the
   selected player's current items.
3. Click any saved profile to load it. This clears the inventory and gives you the items
   from that profile.
4. Click **X** next to a profile to delete it.

Profiles are saved to `BepInEx/config/Aerolt/ItemLoadouts.txt` and persist between runs.
